# Code de conduite

Caffein adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : nous voulons que la participation au projet soit une expérience accueillante et sans harcèlement pour toutes
et tous, quels que soient l'âge, l'apparence, le handicap, l'origine, l'identité ou l'expression de genre, le niveau
d'expérience, la nationalité, la religion ou l'orientation sexuelle.

- Soyez bienveillant·e et respectueux·se, y compris dans les désaccords techniques.
- Critiquez les idées et le code, pas les personnes.
- Pas d'insultes, de propos discriminatoires, de harcèlement, ni de divulgation d'informations privées.

Les comportements inacceptables peuvent être signalés de façon confidentielle aux mainteneurs du projet, via un
signalement privé GitHub. Les mainteneurs peuvent retirer tout contenu ou exclure toute personne qui ne respecte pas
ce code de conduite.
